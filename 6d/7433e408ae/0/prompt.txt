C-M-r (translated from C-M-S-r) runs the command
isearch-backward-regexp (found in global-map), which is an interactive
native-comp-function in ‘isearch.el’.

It is bound to C-M-r and M-s-F.
It can also be invoked from the menu: Edit → Incremental Search →
Backward Regexp....

(isearch-backward-regexp &optional NOT-REGEXP NO-RECURSIVE-EDIT)

Inferred type: (function (&optional t t) t)

Do incremental search backward for regular expression.
With a prefix argument, do a regular string search instead.
Like ordinary incremental search except that your input is treated
as a regexp.  See the command ‘isearch-forward-regexp’ for more information.
